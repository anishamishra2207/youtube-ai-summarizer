# YouTube AI Summarizer

An AI-powered application that summarizes YouTube videos and allows users to ask questions about the video's content.

## Problem Statement

Watching long YouTube videos to find specific information can be time-consuming.

The goal of this project is to build an AI-powered application that extracts the transcript of a YouTube video, generates a meaningful summary, and allows users to ask questions about the video's content.

## Objectives

- Extract the transcript from a YouTube video.
- Generate an AI-powered summary.
- Identify important points and takeaways.
- Allow users to ask questions about the video.
- Provide answers based on the video's content.

## Planned Features

- YouTube URL input
- Transcript extraction
- AI-powered summarization
- Key points extraction
- Video-based question answering
- Semantic search
- RAG
- Error handling
- Web interface
- API backend
